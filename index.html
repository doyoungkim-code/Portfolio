Problem Solving
HF Hub다운로드 진행률이 7GB→2GB→완료로 튀는 문제
원인

환경에 따라 blobs/ 또는 snapshots/에 저장되는데 기존 로직은 blobs/만 합산 → symlink 차단 환경에서 0

해결

두 디렉터리 재귀 측정 후 MAX, atomic move 순간 감소를 단조 증가 clamp

WebRTC강의실 보안망에서 원본 음성 단절
원인

사내망이 client-to-client(P2P) 차단

해결

포트 47878 node-turn 로컬 TURN 내장, UDP 차단 시 TCP fallback으로 relay 우회

Electronfrozen 번들에서 마이크·화면공유·AI 미동작
원인

frozen 경로 어긋남, .mjs/.wasm이 text/plain으로 서빙되어 onnxruntime-web 로드 실패

해결

frozen 경로 해석 헬퍼 + MIME 등록으로 VAD/마이크 파이프라인 정상화

Lifecycle강사가 앱을 닫으면 학생 자막이 사라지는 문제
원인

강사 앱 종료 시 백엔드 즉시 종료 → 수강자 자막 파일 미수신

해결

부모 프로세스 watchdog + 5분 grace shutdown으로 종료 후 다운로드 시간 보장
